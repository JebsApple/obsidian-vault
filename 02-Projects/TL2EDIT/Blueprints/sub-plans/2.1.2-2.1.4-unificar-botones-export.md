## Archivos

### 1. `src/App.tsx`

**Cambio**: Reemplazar los 3 `ExportMenuButton` actuales por 2.

**Código actual** (≈líneas 510-523):
```tsx
<ExportMenuButton kind="docx" icon="ph-file-doc" ... />
<ExportMenuButton kind="psd" icon="ph-stack" ... />
<ExportMenuButton kind="gdocs" hidden />  // o similar
```

**Código nuevo**:
```tsx
<ExportMenuButton
  kind="docx"
  icon="ph-file-doc"
  label="Exportar"
  disabled={!hasExportablePages || exportBusy}
  hasDrive={!!driveUser}
  onPick={(kind, destination) => {
    setExportDestination(destination)
    setExportModal(kind === 'gdocs' ? 'gdocs' : 'docx')
  }}
/>
<ExportMenuButton
  kind="psd"
  icon="ph-stack"
  label="PSD"
  disabled={!hasExportablePages || exportBusy}
  hasDrive={!!driveUser}
  onPick={(kind, destination) => {
    setExportDestination(destination)
    setExportModal('psd')
  }}
/>
```
