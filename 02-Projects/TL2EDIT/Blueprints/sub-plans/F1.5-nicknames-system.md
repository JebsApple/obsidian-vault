## 🥩 Grilling (preguntas que resolver antes de empezar)

1. **Dos pestañas del navegador**: El store usa `localStorage` + listeners. ¿Qué pasa si el usuario modifica apodos en otra pestaña? La pestaña actual no se entera hasta recargar. Considerar escuchar evento `storage` de window para sincronizar entre pestañas.

2. **`applyNicknames()` usa `escapeRegex()` + `replaceAll()`** — ¿Qué pasa si el `nickname` contiene `$&`, `$1`, `` $` ``? `String.replace()` interpreta estos como patrones de reemplazo especiales. Usar callback en vez de string para evitar inyección:
   ```typescript
   result = result.replace(new RegExp(escapeRegex(pattern), 'g'), () => n.nickname)
   ```

3. **Case sensitivity**: ¿Los reemplazos deben ser case-sensitive o case-insensitive? `"NARUTO"` en mayúsculas vs `"naruto"` en minúsculas. La implementación sugerida es case-sensitive. Preguntar al usuario si quiere insensitive.

4. **¿Apodos en el OCR original?** ¿Aplicar apodos al texto original ANTES de traducir mejora la traducción? Sí, porque "TVアニメ放送開始10周年記念" → "10 aniversario" es mejor que dejar el texto original sin procesar.

## Objetivo
Crear sistema de apodos que reemplacen nombres de personajes tanto en el texto original como en el traducido.

```typescript
/** Aplica apodos a un texto. mode='original' usa originalPattern, mode='translated' usa translatedPattern. */
export function applyNicknames(text: string, nicknames: NicknameRule[], mode: 'original' | 'translated'): string {
  let result = text
  for (const n of nicknames) {
    if (!n.enabled) continue
    const pattern = mode === 'original' ? n.originalPattern : n.translatedPattern
    if (!pattern || !n.nickname) continue
    result = result.replace(new RegExp(escapeRegex(pattern), 'g'), () => n.nickname)
  }
  return result
}

function escapeRegex(s: string): string {
  return s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')
}
```

⚠️ **Importante**: Usar `() => n.nickname` en vez del string directo en `.replace()` para evitar inyección de patrones de reemplazo.
