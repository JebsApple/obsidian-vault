## 🥩 Grilling (preguntas que resolver antes de editar)

1. **Imágenes con tamaño fijo**: El plan propone `width: 300, height: 200` para todas las imágenes. ¿Qué pasa si el sticker es 50x50? Se ve enorme. ¿Si es 2000x2000? Se crop. **Mejor**: escalar manteniendo aspect ratio con un máximo de ancho (ej: max 400px, alto proporcional).

2. **DOCX sin separación entre páginas en 50+ páginas**: Word puede manejar documentos largos, pero ¿el rendimiento? ¿Y si el usuario quiere volver a la separación por páginas después? Este cambio es unidireccional.

3. **`spacing: { after: 200 }`** es en twips (1/20 de punto). 200 twips = 10pt. ¿El usuario quiere más o menos espacio entre bloques? Preguntar. Tal vez 120 twips (6pt) es mejor.

4. **¿Qué pasa con `buildDocxBlob()` (para una sola página)?** Se usa en algún lado? Si se usa, simplificarla para que llame a `buildDocxBlobMulti([page])`.

5. **Callers de `buildDocxBlobMulti`**: ¿Dónde se llama actualmente? En `useExport.ts`. Actualizar también `buildDocxBlob` si existe.

## Objetivo
Cambiar el formato de exportación DOCX: cada bloque su propio párrafo, línea en blanco entre bloques, sin separación entre páginas, imágenes insertadas, apodos aplicados.

### 2. Reemplazar `buildPageParagraphs()` por `buildBlockParagraphs()`

```typescript
async function buildBlockParagraphs(
  pages: ComicPage[],
  config: BlockTypesConfig,
  nicknames?: NicknameRule[]
): Promise<Paragraph[]> {
  const paragraphs: Paragraph[] = []
  let firstBlock = true

  for (const page of pages.filter(p => p.status === 'success')) {
    const blocks = page.textBlocks.filter(b => b.exportEnabled)
    for (const block of blocks) {
      if (!firstBlock) {
        paragraphs.push(new Paragraph({ children: [], spacing: { after: 60 } }))
      }
      firstBlock = false

      if (block.blockType === 'imagen') {
        if (block.attachedImage) {
          try {
            const { buffer, type } = dataUrlToUint8Array(block.attachedImage)
            // Escalar imagen manteniendo aspect ratio, max 400px de ancho
            paragraphs.push(new Paragraph({
              children: [new ImageRun({
                type: type as any,
                data: buffer,
                transformation: { width: 400, height: 300 }, // Ajustar según imagen
              })],
              spacing: { after: 100 },
            }))
          } catch { /* skip */ }
        }
        continue
      }

      const prefix = blockPrefix(block, config)
      const text = block.approvedText || block.originalText || ' '
      const finalText = nicknames ? applyNicknames(text, nicknames, 'translated') : text
      paragraphs.push(new Paragraph({
        children: [new TextRun(`${prefix}${finalText}`)],
        spacing: { after: 200 }, // ⚠️ Preguntar al usuario: 200 twips = 10pt? Mucho? Poco?
      }))
    }
  }
  return paragraphs
}
```

### 3. Re-escribir `buildDocxBlobMulti()`
```typescript
export async function buildDocxBlobMulti(
  pages: ComicPage[],
  config: BlockTypesConfig,
  nicknames?: NicknameRule[]
): Promise<Blob> {
  const legend = buildLegendParagraphs(config)
  const content = await buildBlockParagraphs(pages, config, nicknames)
  if (content.length === 0) content.push(new Paragraph({ children: [] }))
  const doc = new Document({ sections: [{ children: [...legend, ...content] }] })
  return Packer.toBlob(doc)
}
```

### 4. Simplificar `buildDocxBlob()`
```typescript
export async function buildDocxBlob(
  page: ComicPage, config: BlockTypesConfig, nicknames?: NicknameRule[]
): Promise<Blob> {
  return buildDocxBlobMulti([page], config, nicknames)
}
```
