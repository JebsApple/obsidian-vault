# Sub-Plan F1.1: Fix Header Scroll (PR #82)

**Agente**: Sub-agente A
**Dificultad**: BAJA | **Archivos**: 4 | **Estimación**: 1–2h

## Objetivo
Evitar que el header se desplace al hacer focus en inputs de la UI. El scroll del canvas no debe afectar la posición del header.

## Contexto
- `src/App.tsx` contiene el layout principal con header + canvas
- `src/components/Select.tsx` es un dropdown personalizado
- `src/components/SpellCheckedTextarea.tsx` es un textarea con corrector ortográfico
- En estos 3 componentes hay `focus()` que causan scroll no deseado

## Archivos a modificar

### 1. `src/App.tsx`
Buscar las líneas donde se hace focus a elementos del header. Hay 3 `focus()` que necesitan `{ preventScroll: true }`.

```typescript
// Antes:
element.focus()
// Después:
element.focus({ preventScroll: true })
```

### 2. `src/components/Select.tsx`
Buscar `focus()` en el select y agregar `{ preventScroll: true }`.

### 3. `src/components/SpellCheckedTextarea.tsx`
Buscar `focus()` en el textarea y agregar `{ preventScroll: true }`.

### 4. NO crear `src/hooks/useAnclarScrollRaiz.ts`
No se necesita hook. El fix son 3 cambios de 1 línea cada uno. Si el PR original lo requería, es porque la aproximación anterior era más compleja de lo necesario.
