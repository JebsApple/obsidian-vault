## Objetivo
Evitar que el header se desplace al hacer focus en inputs de la UI. El scroll del canvas no debe afectar la posición del header.

## Contexto
- `src/App.tsx` contiene el layout principal con header + canvas. El header usa `position: sticky` o `fixed`? Verificar layout antes de aplicar fix.
- `src/components/Select.tsx` es un dropdown personalizado
- `src/components/SpellCheckedTextarea.tsx` es un textarea con corrector ortográfico
- Hay 3 `focus()` que causan scroll no deseado. CÓMO IDENTIFICARLOS: abrir la app, abrir DevTools, hacer focus en cada input del header, ver si el scroll se mueve. Los que mueven el scroll son los que necesitan fix.

## Archivos a modificar

### 1. `src/App.tsx`
Buscar las líneas donde se hace focus a elementos del header y agregar `{ preventScroll: true }`.

```typescript
// Antes:
element.focus()
// Después:
element.focus({ preventScroll: true })
```

⚠️ **Precaución**: Si el focus está en un elemento que NO es visible actualmente en el viewport, `preventScroll` evitará que el usuario lo vea. Solo aplicar en inputs del HEADER, no en elementos del canvas o sidebar.

### 2. `src/components/Select.tsx`
Buscar `focus()` en el select y agregar `{ preventScroll: true }`.

### 3. `src/components/SpellCheckedTextarea.tsx`
Buscar `focus()` en el textarea y agregar `{ preventScroll: true }`.

### 4. NO crear `src/hooks/useAnclarScrollRaiz.ts`
No se necesita hook. El fix son 3 cambios de 1 línea cada uno.
