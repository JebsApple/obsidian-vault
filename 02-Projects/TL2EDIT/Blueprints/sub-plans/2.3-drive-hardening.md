## 🥩 Grilling (preguntas que resolver antes de editar)

1. **`driveFetchWithRetry()` en POST vs GET**: Las operaciones POST (crear archivo, subir) no son idempotentes — reintentar un POST puede crear archivos duplicados. La función debe distinguir: reintentar solo methods GET y PUT, no POST.

2. **El test existente (`googleDrive.test.ts`) usa mocks de fetch**: Si se envuelve `driveFetch()` con una nueva función, el mock apunta a `fetch()` global, no a la función wrapper. Verificar que el mock sigue funcionando con la nueva capa.

3. **403 Forbidden vs 429 Too Many Requests**: 403 puede ser "quotaExceeded" (retryable después de esperar) o "insufficientPermissions" (no retryable). 429 y 5xx son retryables. Distinguir entre errores retryables y no retryables.

Hacer las llamadas a Google Drive API más robustas.

## Cambios

### 1. Exponential Backoff

```typescript
const RETRYABLE_STATUSES = [429, 500, 502, 503]
const RETRYABLE_METHODS = ['GET', 'PUT', 'PATCH']  // NO POST (crea duplicados)
const MAX_RETRIES = 3
const BASE_DELAY_MS = 1000

async function driveFetchWithRetry(
  accessToken: string, url: string,
  init?: RequestInit, signal?: AbortSignal,
  retries = MAX_RETRIES
): Promise<Response> {
  const method = (init?.method || 'GET').toUpperCase()
  const canRetry = RETRYABLE_METHODS.includes(method)

  for (let attempt = 0; attempt <= retries; attempt++) {
    try {
      const res = await driveFetch(accessToken, url, init, signal)
      if (res.ok || !canRetry || !RETRYABLE_STATUSES.includes(res.status)) {
        return res
      }
      if (attempt === retries) return res  // último intento, devolver error
      await new Promise(r => setTimeout(r, BASE_DELAY_MS * Math.pow(2, attempt)))
    } catch (err) {
      if (attempt === retries || !canRetry) throw err
      if (err instanceof TypeError) { // network error
        const delay = BASE_DELAY_MS * Math.pow(2, attempt)
        await new Promise(r => setTimeout(r, delay))
        continue
      }
      throw err
    }
  }
  throw new Error('Max retries exceeded')
}
```
