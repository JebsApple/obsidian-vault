# Sub-Plan F1.4: Scroll Root en Fase Captura — StitchModal

**Agente**: Sub-agente A (después F1.1)
**Dificultad**: BAJA | **Archivos**: 1 | **Estimación**: 0.5h

## Objetivo
Prevenir que el scroll del canvas afecte la posición del modal de Stitch cuando está abierto.

## Archivo a modificar

### `src/components/StitchModal.tsx`
Agregar un `useEffect` que capture el evento scroll en fase capture cuando el modal está montado:

```typescript
useEffect(() => {
  const handler = () => {
    // Anclar scroll del body/root a 0 mientras el modal esté abierto
    document.documentElement.scrollTop = 0
    document.body.scrollTop = 0
  }
  document.addEventListener('scroll', handler, { capture: true })
  return () => document.removeEventListener('scroll', handler, { capture: true })
}, [])
```

No se necesita hook compartido. Es específico de StitchModal.
