## 🥩 Grilling (preguntas que resolver antes de empezar)

1. **¿localStorage es suficiente para guardar series?** Si el usuario tiene 50+ series con múltiples overrides cada una, localStorage puede llenarse (~5MB límite). Considerar: ¿guardar en IndexedDB en vez de localStorage? ¿O en un archivo en Drive? Para empezar, localStorage es aceptable, pero documentar la limitación.

2. **¿Cómo se pasan los `seriesOverrides` a `resolveBlockType()`?** El plan no especifica el mecanismo. Opciones:
   - **React Context**: crear `SeriesContext` que provee los overrides activos. Todos los componentes que usan `resolveBlockType` consumen el contexto.
   - **Props**: pasar `seriesOverrides` manualmente desde App.tsx hasta cada componente.
   - **Recomendación**: Context, para evitar prop drilling (los overrides se usan en 4+ componentes en distintas ramas del árbol).

3. **¿Custom types en series?** El plan itera sobre `BLOCK_TYPES` que excluye `custom`. Pero las series también deberían poder overridear tipos personalizados. Agregar `typeConfig.customTypes` a la iteración.

4. **¿Qué pasa si se borra una serie que está activa?** El hook debe limpiar `currentSeries` si se elimina.

5. **Persistencia entre sesiones**: Si el usuario cierra y abre la app, ¿la serie activa se recuerda? Guardar `activeSeriesId` en localStorage aparte de la lista.

## Objetivo
Cada serie puede tener sus propios overrides de prefijos, labels y fuentes para los tipos de bloque.

### 2. Modificar `resolveBlockType()` en `src/types.ts`
```typescript
export function resolveBlockType(
  typeConfig: BlockTypesConfig,
  blockType: string,
  seriesOverrides?: SeriesBlockTypeOverride[]
): { label: string; prefix: string; fontFamily: string; icon: string } {
  const base = resolveBaseBlockType(typeConfig, blockType)
  if (seriesOverrides) {
    const override = seriesOverrides.find(o => o.blockTypeId === blockType)
    if (override) {
      return {
        ...base,
        label: override.label ?? base.label,
        prefix: override.prefix ?? base.prefix,
        fontFamily: override.fontFamily ?? base.fontFamily,
      }
    }
  }
  return base
}
```
