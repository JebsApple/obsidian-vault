**Agente**: Sub-agente D (después F1.5)

## Objetivo
Aplicar los apodos al texto traducido/aprobado antes de escribirlo en el DOCX exportado. Usar la función `applyNicknames()` creada en F1.5.

## Dependencia
Requiere F1.5 completado (existe `src/hooks/useNicknames.ts` con `applyNicknames()`).

```typescript

```

```typescript
export async function buildDocxBlobMulti(
```

**Cambio 3**: En el loop donde se escribe cada bloque, aplicar apodos:
```typescript
const text = block.approvedText || block.originalText || ' '
const finalText = nicknames ? applyNicknames(text, nicknames, 'translated') : text
const entry = `${prefix}${finalText}`
```

**Cambio 4**: Actualizar `useExport.ts` para pasar los nicknames desde el hook `useNicknames()` a `buildDocxBlobMulti()`.
