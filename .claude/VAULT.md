# Vault Protocol — Instrucciones para Claude Code / Opencode

Lee `90-Sistema/PROTOCOLO.md` al inicio de cada sesión.
Lee `CONTEXTO.md` para saber dónde se quedó la sesión anterior.

## Reglas rápidas

1. **Siempre actualizar CONTEXTO.md al cerrar una sesión** — proyecto, resumen, próximos pasos.
2. **Frontmatter unificado** — toda nota nueva usa `tipo`, `creado`, `tags`.
3. **Sesiones** → `02-Projects/<proyecto>/sesion-YYYY-MM-DD.md`, no en la raíz.
4. **Decisiones** → `decision-<tema>.md` dentro del proyecto con estado `vigente|reemplazada`.
5. **Conocimiento nuevo** → `04-Resources/Zettelkasten/<concepto>.md` con enlaces a notas relacionadas.

## Stack del usuario

- Backend: Go (Gin/Echo), PostgreSQL, Docker, Nginx
- Frontend: Vue 3, Chart.js, Tailwind
- Desktop: Hyprland/Wayland, Arch Linux (CachyOS), Waybar
- AI: Claude Code, opencode, Fable 5

Ver `user-context.md` en `03-Areas/Herramientas-IA/fable-knowledge/` para detalle completo.
